목표달성 - 투두 루틴

‘목표달성 - 투두 루틴’(이하 ‘앱’)은 별도의 회원가입 없이 만다라트 목표, 할 일 및 루틴을 관리할 수 있는 서비스입니다. 사용자가 입력한 데이터는 원칙적으로 사용자 기기 내부에 저장되며, 앱 운영자가 이를 수집하거나 자체 서버에 저장·전송하지 않도록 설계되었습니다.

본 방침은 앱의 데이터 처리 방식을 설명합니다. 실제 배포 버전의 기능 및 포함된 외부 SDK에 따라 내용이 변경될 수 있습니다.

1. 처리하는 정보 및 이용 목적

앱은 서비스 제공을 위해 기기 내부에서 다음 데이터를 생성·저장·처리할 수 있습니다.

  • 목표 및 계획: 만다라트의 핵심 목표, 하위 목표, 실행 항목, 세부 실행 항목, 메모
  • 할 일·루틴: 할 일 내용, 예정 날짜, 반복 요일, 완료 여부, 실행 기록
  • 앱 설정: 화면 테마, 정렬 방식, 주 시작 요일 및 기타 환경설정
  • 백업 데이터: 사용자가 직접 내보내거나 불러오는 데이터 파일

이 정보는 앱 화면 표시, 목표·일정 관리, 완료 기록 보존, 사용자가 요청한 백업·복원 기능을 위해 기기 안에서 처리됩니다. 앱은 회원가입을 제공하지 않으며, 서비스 이용을 위해 이름·이메일 주소·전화번호 등의 입력을 요구하지 않습니다.

2. 저장 위치 및 외부 전송

사용자가 작성한 목표, 할 일, 루틴 및 실행 기록은 기기 내부의 로컬 데이터베이스(SQLite)에 저장됩니다. 앱 운영자는 해당 데이터를 조회할 수 있는 계정 시스템이나 자체 동기화 서버를 운영하지 않습니다.

다만 사용자가 직접 백업 파일을 공유·저장하는 경우 선택한 파일 앱, 클라우드 저장 서비스 또는 공유 대상에 데이터가 전달될 수 있습니다. 또한 기기 운영체제의 백업 설정에 따라 앱 데이터가 운영체제 제공 백업 서비스에 포함될 수 있습니다. 이러한 처리에는 사용자가 선택한 서비스와 기기 설정이 적용됩니다.

3. 제3자 제공 및 처리 위탁

앱 운영자는 앱 내부에 저장된 목표·할 일·루틴 데이터를 광고 사업자나 다른 제3자에게 제공하지 않으며, 자체 서버에서 해당 데이터를 처리하도록 위탁하지 않습니다.

사용자가 기기의 공유 기능 또는 외부 저장소를 직접 사용하는 경우에는 해당 서비스의 개인정보처리방침이 적용될 수 있습니다.

4. 데이터 보유 및 삭제

앱 데이터는 사용자가 삭제하거나 앱에서 전체 데이터 초기화를 실행하기 전까지 기기 내부에 보관될 수 있습니다. 사용자는 앱 내에서 개별 목표, 할 일 및 루틴을 삭제하거나 설정 → 데이터 관리 → 전체 데이터 초기화 기능을 이용하여 앱 내부 데이터를 삭제할 수 있습니다.

앱 삭제, 기기 초기화, 기기 변경 등으로 로컬 데이터가 유실될 수 있으며, 운영자가 이를 복구할 수는 없습니다. 또한 앱 밖으로 내보낸 백업 파일이나 운영체제·외부 서비스에 별도로 보관된 사본은 앱 내 초기화만으로 삭제되지 않습니다. 해당 파일과 사본은 사용자가 저장한 위치에서 직접 관리해야 합니다.

5. 데이터 백업·복원 및 보안

사용자는 앱의 백업·복원 기능을 통해 데이터를 파일로 내보내거나 가져올 수 있습니다. 백업 파일에는 목표, 할 일, 루틴 및 실행 기록 등 개인적인 내용이 포함될 수 있으므로 신뢰할 수 있는 저장 위치를 선택하고, 제3자에게 노출되지 않도록 주의해 주시기 바랍니다.

앱 데이터는 운영체제가 제공하는 앱 저장 영역에 보관되며, 기기의 잠금 설정, 운영체제 보안 상태 및 사용자의 백업 파일 관리 방식 등에 따라 보호 수준이 달라질 수 있습니다. 백업 파일 자체에 별도 암호화가 적용된다고 보장하지 않습니다.

6. 개인정보 관련 이용자 권리

앱은 별도의 사용자 계정을 운영하지 않으므로, 앱 운영자가 기기 내부에 저장된 기록을 원격으로 열람·수정·삭제할 수 없습니다. 사용자는 앱에서 자신의 데이터를 확인, 수정, 삭제하고 백업 파일을 내보낼 수 있습니다.

앱의 개인정보 처리 방식에 관한 문의는 아래 연락처를 이용해 주시기 바랍니다.

7. 아동의 개인정보

앱은 회원가입이나 연령 확인을 위한 개인정보 입력을 요구하지 않습니다. 또한 운영자가 아동의 개인 기록을 수집하기 위한 별도 기능을 제공하지 않습니다. 보호자는 기기의 사용·공유·백업 설정을 통해 아동의 앱 데이터 관리에 주의를 기울여 주시기 바랍니다.

8. 외부 서비스 및 기능 변경

현재 기획 기준으로 앱은 자체 서버 기반의 사용자 분석, 맞춤형 광고, 계정 연동 및 클라우드 동기화 기능을 제공하지 않습니다. 향후 이러한 기능이나 개인정보를 외부로 전송하는 외부 SDK가 도입되는 경우에는 실제 처리 내용을 확인하고 본 방침과 앱스토어 개인정보 관련 표시를 사전에 수정하겠습니다.

9. 개인정보처리방침의 변경

법령, 앱 기능 또는 데이터 처리 방식이 변경되는 경우 본 방침을 개정할 수 있습니다. 중요한 변경 사항은 앱 내 안내 또는 공개된 개인정보처리방침 페이지를 통해 알리겠습니다. 변경된 방침에는 적용되는 시행일을 표시합니다.
